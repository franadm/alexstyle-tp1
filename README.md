# ALEXSTYLE Manager - Trabajo Práctico N°3

Prototipo desarrollado en Java enfocado en la aplicación de los pilares de la **Programación Orientada a Objetos (POO)**:
- **Abstracción y Herencia:** Clases abstractas (`Persona`, `Servicio`) y subclases especializadas (`Barbero`, `CorteCabello`).
- **Polimorfismo:** Redefinición de métodos para el cálculo dinámico de tarifas.
- **Encapsulamiento:** Ocultamiento de atributos y uso de métodos de acceso.
- **Manejo de Excepciones:** Excepción personalizada de negocio (`AlexstyleExcepcion`) y control robusto de errores de entrada en menús (`InputMismatchException`).
